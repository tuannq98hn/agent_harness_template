# Visual Parity Rules

Use this file when implementing UI from design references.

## Required Checks

- Layout hierarchy matches source design.
- Spacing and alignment are consistent with design tokens.
- Typography, color, border radius, and elevation/shadow are consistent.
- Empty/loading/error states are handled.
- Responsive behavior is documented or tested.
- Platform-specific differences are intentional.
