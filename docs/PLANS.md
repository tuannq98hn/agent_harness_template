# PLANS.md

This document explains how planning artifacts are organized.

## Plan Locations

- Active work: `docs/exec-plans/active/`
- Completed work: `docs/exec-plans/completed/`
- Technical debt: `docs/exec-plans/tech-debt-tracker.md`

## Plan Lifecycle

1. Create an execution plan in `active/`.
2. Define problem, scope, non-goals, implementation steps, validation, and risks.
3. Implement in small steps.
4. Update status while working.
5. Move completed plans to `completed/` with verification notes.
6. Add unresolved issues to the tech debt tracker.
