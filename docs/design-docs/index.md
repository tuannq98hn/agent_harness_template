# Design Docs Index

Use this folder for design source-of-truth documents.

Recommended files:

- `core-beliefs.md` — design principles and product taste
- `design-system.md` — typography, colors, spacing, components
- `screen-map.md` — screen list and navigation map
- `visual-parity-notes.md` — comparison notes against source design

## Agent Rule

Before implementing UI, read the relevant design doc and product spec. Do not invent UI beyond the documented design unless explicitly requested.
