# Bug reports

One file per reproduced issue: `docs/bugs/<ISSUE-ID>.md`, created from `_template.md` by the tester.
It is the hand-off between the tester (reproduce) and the implementer (fix), and the proof for the reviewer.

Lifecycle: **Reproduce I-…** (tester) → report + skipped repro test → **Fix I-…** (implementer)
un-skips the test, fixes the root cause, fills *Fix* → reviewer re-runs → *Verification*.
