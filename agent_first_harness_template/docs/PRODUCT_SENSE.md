# PRODUCT_SENSE.md

This document captures product judgment that should guide implementation.

## Product Goal

> Describe the core user problem and desired product outcome.

## Target Users

> Describe primary users, secondary users, and their contexts.

## Product Principles

- Optimize for user value, not only feature count.
- Avoid adding flows that are not supported by product specs.
- Prefer simple, understandable behavior.
- Make monetization, permissions, payments, and account behavior transparent.
- Respect platform policies and user trust.

## Decision Questions

Before adding or changing behavior, ask:

1. Which user problem does this solve?
2. Is this in scope for the current spec?
3. What could confuse the user?
4. What could break existing behavior?
5. How will success be measured?
