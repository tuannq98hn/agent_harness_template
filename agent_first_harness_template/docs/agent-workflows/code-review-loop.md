# Code Review Loop

Use this checklist before considering work complete.

## Review Checklist

- [ ] Change matches requested scope
- [ ] Architecture boundaries respected
- [ ] Naming and structure are consistent
- [ ] Error handling is explicit
- [ ] Security-sensitive behavior reviewed
- [ ] Tests/checks updated or documented
- [ ] No secrets or local-only files added
- [ ] Documentation updated if behavior changed
- [ ] No unrelated formatting churn

## Review Output Format

```md
## Review Summary

## Issues Found

## Fixes Applied

## Remaining Risks

## Verification
```
