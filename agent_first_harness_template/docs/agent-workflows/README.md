# Agent Workflows

This folder defines repeatable workflows for AI agents and humans.

Core idea: agents should not only implement; they should plan, execute, verify, document, and report.

- `feature-implementation-loop.md` — default for features
- `bug-reproduction.md` — reproduce (tester) → fix (implementer) hand-off for bugs
- `bug-fix-loop.md` — fixing a bug
- `code-review-loop.md` — review checklist
- `multi-agent-loop.md` — how the harness loop, runtimes, limits and asks work
- `release-checklist.md` — before shipping
